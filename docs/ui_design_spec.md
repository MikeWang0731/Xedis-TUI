## 二、 界面架构与多预设分栏系统 (Layout Architecture & Presets)

为了满足不同用户在不同工作阶段的需求（例如日常开发写命令 vs 线上压测盯盘），Xedis-TUI 提供**灵活的动态分栏系统**与 **4 种开箱即用的布局预设 (Layout Presets)**：

### 1. 四大布局预设对比

| 预设模式 | 分栏比例 (左 : 右) | 核心场景 | 界面行为与自适应策略 |
| :--- | :--- | :--- | :--- |
| **⚖️ 平衡模式 (Balanced)** <br>*(默认推荐)* | **58% : 42%** | 日常开发、综合调试 | 左侧完整展示结构化返回值，右侧完整展示监控走势、集群分片卡片与慢查 |
| **💻 操作沉浸模式 (Focus / CLI)** | **75% : 25%** | 宽表格查询、大 JSON 对象查看、脚本编写 | 左侧最大化，右侧自动折叠为 **Mini 紧凑看板**（只保留关键内存水位与 QPS 胶囊标签） |
| **📊 运维看板模式 (Ops / Monitor)** | **35% : 65%** | 大促保障、线上排障、集群拓扑巡检 | 左侧保留精简输入流，右侧展开为 **全景大看板**（并排展示全部 Shard 槽位图、慢查明细与热点 Key） |
| **🔲 极简纯流模式 (Zen / Pure Stream)** | **100% : 0%** | 传统 Redis-cli 极简重度用户 | 彻底隐藏右侧边栏，独享 100% 终端屏幕空间，随时按快捷键即可重新拉出看板 |

> 💡 **用户持久化与切换方式**：
> - **快捷键热切换**：按 `F5` 或 `Ctrl+B` 循环切换 4 种预设；
> - **微调分栏**：支持 `Ctrl+[` / `Ctrl+]` 以 5% 步长自由拖拽/微调比例；
> - **配置文件持久化**：可在 `~/.config/xedis/config.toml` 中配置 `default_layout = "balanced" | "focus" | "monitor" | "zen"`。

## 三、 核心模块深度设计

### 1. 左侧：类 AI Agent 交互指令流 (Interactive Command Stream)
- **卡片式呈现 (Block Cards)**：每一次命令输入与返回均打包为一个独立 Card，清晰展示：
  - **执行目标标记**：`[DIRECT]`（单机直连）、`[@node-1]`（指定分片）或 `[CLUSTER-BROADCAST]`（全集群广播）。
  - **耗时与时间戳**：精准到微秒级执行延迟（如 `0.42ms`），便于初学者直观感知命令开销。
  - **多形态自动格式化渲染**：
    - **Hash / Dict 类型**：自动转为规整的 **ASCII/Unicode 表格 (Table)**。
    - **List / Set / Scan 结果**：语法高亮 **JSON / 数组树形视图 (Tree View)**。
    - **String / Raw**：支持彩色语法高亮，长文本可折叠展开。

### 2. 智能命令提示与快捷触发器 (`@` 与 `/`)
- **`/` 触发快捷排障与常用管理宏 (Command Macros)**：
  - `/scan [pattern]`：初学者经常误用 `KEYS *` 导致宕机，输入 `/scan` 自动转换为安全非阻塞迭代。
  - `/bigkeys`：一键触发大 Key 探测与内存占比分布统计。
  - `/slowlog`：一键调出最近慢查询分析。
  - `/clients`：查看异常高频或长阻塞连接，支持一键 `kill`。
- **`@` 触发多节点/分片路由选择器 (Node Picker)**：
  - 集群或主从模式下，初学者无需手动在终端新开连接，输入 `@` 即可弹出当前集群所有 Node 列表（如 `@master-1`、`@192.168.1.10:6379`、`@all-replicas`），直接将命令定向派发。

### 3. 初学者护栏 (Novice Safety Guard & Interceptor)
- **高危操作阻断弹窗**：当检测到 `FLUSHALL`、`FLUSHDB`、`KEYS *`、`SHUTDOWN`、`CONFIG SET` 等极易导致故障的操作时：
  - 终端立即弹出高亮警告 Modal（黄色/红色高对比度框）。
  - 解释**为什么危险**（例如：“KEYS * 在百万级数据下会阻塞 Redis 单线程数秒，引发雪崩”）。
  - 提供**安全替代方案**（如“推荐使用 `/scan` 或 `SCAN 0 MATCH ...`”）。
  - 需显式通过 `Enter` 二次确认或输入 `yes`，防止手滑误操作。

### 4. 右侧：多维信息看板 (Multi-View Telemetry Sidebar)
支持通过 `Tab` 或 `F2/F3/F4` 快速切换以下 3 大模式：
1. **监控概览 (Telemetry & Health)**：
   - 内存 Used vs Maxmemory 进度条、内存碎片率 (Fragmentation Ratio)、驻留内存 (RSS)。
   - QPS 吞吐与 CPU 占用的终端 Sparkline 实时走势折线图。
   - 活跃连接数、命中率 (Hit Rate %)、总 Key 数。
   - 历史执行命令快照。
2. **集群拓扑 (Cluster Topology)**：
   - 动态 Shard 树状图，清晰标注每个 Master 对应的 Replicas 节点。
   - 每个分片承载的 **Slot 槽位区间 (0~16383)** 及键容量。
   - 节点健康指示灯（🟢 正常 / 🟡 复制同步中 / 🔴 离线故障）。
3. **慢查与排障 (Troubleshoot & Slowlog)**：
   - 实时监听并在侧边栏滚动输出 SLOWLOG 事件。
   - 内置智能解释器，标注大 Key 风险与优化建议。

## 四、 交互快捷键矩阵 (Keybinding Matrix)

| 快捷键 | 功能说明 | 适用场景 |
| :--- | :--- | :--- |
| `Tab` | 在【左侧输入框】与【右侧看板】之间切换焦点 | 键盘全流操作 |
| `F5` / `Ctrl + B` | 快速循环切换 **4 种布局预设**（平衡 / 沉浸 / 运维 / 纯流） | 视口比例快速适配 |
| `Ctrl + [` / `Ctrl + ]` | 以 5% 步长向左/向右微调分栏比例 | 像素级自定义宽度 |
| `/` | 唤起常用运维/排障快捷命令菜单 | 寻找常用命令/避免误操作 |
| `@` | 唤起集群节点选择菜单 | 集群/主从定向查询 |
| `Ctrl + P` / `Cmd + K` | 唤起全局命令调色板 (Command Palette) | 切换实例、修改主题、导出日志 |
| `Ctrl + L` | 清屏当前 Command Stream | 释放终端可视空间 |
| `F1` | 呼出当前上下文的语法助手与新人排障指南 | 查看命令参数说明 |
| `F2` / `F3` / `F4` | 快速切换右侧看板（监控概览 / 集群拓扑 / 排障慢查） | 一键直达特定视图 |
| `Esc` | 关闭弹窗 / 取消命令补全 / 退出当前模态 | 通用取消 |

## 五、 配色系统与终端设计规范 (Design Tokens)

- **基准底色**：`#0B0F19` (Deep Obsidian Dark)，避免强烈的纯黑，呈现现代高级感。
- **品牌与重点强调色**：
  - 核心 Cyan: `#06B6D4` (命令高亮、边框与光标)
  - 节点 Indigo: `#6366F1` (`@node` 标签、分片 ID)
  - 健康 Emerald: `#10B981` (正常状态点、成功返回值)
  - 警示 Amber: `#F59E0B` (碎片率异常、慢查询告警)
  - 危险 Crimson: `#EF4444` (高危命令拦截、节点宕机)
- **字体与图标**：
  - 推荐等宽字体：`JetBrains Mono` / `Fira Code` / `Cascadia Code`
  - 图标集：支持 Nerd Font 图标（如 ``、``、`⚡`、`🌐`、`💾`、`🚨`），无 Nerd Font 时自动降级为 ASCII/Unicode 符号。
